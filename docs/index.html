Data and method notes
  • Source: registers compiled from the Uganda Legal Information Institute (ULII): 375 judgments 2015–2025 and 107 more from 2026 (to 16 November). 2026 is a partial year, so its raw count is not comparable with full years; rates per 1,000 ULII judgments are.
  • Issues, outcomes, party types and arbitration application types are coded by transparent keyword rules from short register fields (src/code/rules.py). They are being validated against a manually coded gold set of 150 judgments.
  • ULII holds only part of each year's judgments, especially before 2020, so litigated cases on ULII are a filtered sample.
  • Party type is taken from the first-named party on each side; the first-named party is treated as the initiator.
  • Duration uses the filing year in the case number and applies only to suits and appeals.
